<h2>HOW TO USE OR TEST THIS PROJECT</h2>
 <p>You can use this by using local host like through XAMPP or vai uploading in your hosting</p>
 <p>I have given two folder 1st for Local Server(XAMPP), and 2nd for hosting on online server.</p>
 <hr>
 <h3><b><span style="color:tomato;">Note:</span></b>You must have to configure database to run this project otherwise it will show error 500</h3>

 <p style="color:seagreen;">Edit and manually setup database.php file which is present at this location: (For LocalServer) or (For Online Server)/config/database.php </p>
 
 Remember to configure database, structure of mysql database is given in both Local as well as Online server.
